# Cloudflare Git-connected build trigger

This documentation-only file was added to trigger the first Git-connected Cloudflare build for the `faultlinebrief-website-d1-isolated` Worker.

It does not change application code, Next.js configuration, Wrangler configuration, D1 bindings, R2 bindings, runtime variables, routes, or website content.

Production deployment should be reviewed in Cloudflare before any further application changes.
